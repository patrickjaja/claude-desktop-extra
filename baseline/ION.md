## How It's Served

```
Main process (v4.29.0 names - these change every release; v4.4212.0: `_Gr`=`Dqr`, `vq`=`wJ`, the lstat helper `vGr`=`Oqr`, logic unchanged):
  h8r(_Gr(), rendererConfigGetter, ...)

_Gr()  -> path.join(vq(), app.isPackaged ? "ion-dist.asar" : "ion-dist")
vq()   -> process.resourcesPath when packaged (exe-adjacent resources/ in every install)
m8r()  -> for an .asar path: original-fs lstat must say regular FILE, then stat index.html
          inside it; otherwise log "[custom-3p] ... (ion-dist.asar) are missing or are
          not a regular file" once and serve nothing
r8r()  -> reads index.html (asar-aware fs) and injects window.__DESKTOP_3P_PUBLIC_CONFIG__
p8r()  -> the app://localhost/api/* routes (bootstrap, account settings, gated imports)
h8r()  -> protocol.handle("app", ...): hostname must be localhost, Origin must match
```

Until v3.6556.2 the same handler served the plain directory (`QKr(path.join(oJ(),"ion-dist"),...)` there). All our packages keep `app.isPackaged` true (the Electron binary is renamed `claude`, on Nix too), so they always take the `ion-dist.asar` branch.

The 3P setup window opens `app://localhost/setup-desktop-3p` in a `BrowserWindow` with `mainView.js` as preload.

## Patterns to Monitor on Upstream Updates

When a new version drops, re-run these checks against a fresh extract of `resources/ion-dist.asar` (v4.29.0+; earlier releases shipped the `resources/ion-dist/` dir directly):

Use GNU `grep -a` (or python), not `rg`: the minified chunks can contain NUL bytes and `rg` then silently returns nothing, even with `-a`. Character classes must be POSIX (`[A-Za-z0-9_$]`), `\w` inside brackets is not portable.

```bash
asar extract ./tmp/extract/usr/lib/claude-desktop/resources/ion-dist.asar ./tmp/ion-dist
ION=./tmp/ion-dist
asar list --is-pack ./tmp/extract/usr/lib/claude-desktop/resources/ion-dist.asar | grep -c '^unpack '   # 0; non-zero = the build's repack must learn the --unpack layout

# 1. Find the two patch targets by content (filenames AND chunk families change;
#    sub-patch A = the only mountPath:{ file, sub-patch B = the only ternary file)
grep -alE 'mountPath:\{mac:' "$ION/assets/v1/"*.js
grep -aoE '[A-Za-z0-9_$]+=== *[A-Za-z0-9_$]+\.Win32\?[A-Za-z0-9_$.]+\.win:[A-Za-z0-9_$.]+\.mac' "$ION/assets/v1/"*.js
grep -al 'org-plugins' "$ION/assets/v1/"*.js   # also hits the admin-plugins data-testid chunk (c84e37421-* since v2.2553.0, c90a58c4a-* before), a release-notes data chunk (cb63ed069-*) and, since v2.7032.0, the org-plugins status UI chunk (c99ed1520-*, `org-plugins-session-host-line` / `org-plugins-managed-note` data-testids) - neither is a target

# 2. Verify org-plugins still only has mac/win (or was updated upstream)
grep -aoE 'mountPath:\{.{0,200}\}' "$ION/assets/v1/"*.js

# 3. Check for new platform-gated code
grep -al 'darwin' "$ION/assets/v1/"*.js | wc -l

# 4. Check for new mac/win-only paths without linux
grep -aoE '/Library/Application Support.{0,60}' "$ION/assets/v1/"*.js
grep -aoE '%ProgramFiles%.{0,60}' "$ION/assets/v1/"*.js

# 5. Verify platform enum still exists (location-agnostic: the enum left index-*
#    at v1.28929.0 and hops shared-* chunk numbers between releases - grep the dir)
grep -aoE 'Darwin="darwin".{0,40}Linux="linux"' "$ION/assets/v1/"*.js

# 6. Check for new IPC bridges or native calls (since v1.32352.1 the bindings
#    live in shared-* chunks, no longer in index-*.js - grep the whole dir)
grep -ac 'claudeAppBindings' "$ION/assets/v1/"*.js | grep -v ':0$'

# 7. Bundle size sanity check (large changes = structural refactor). These are the
#    commands behind every number in Bundle Stats (v4.4212.0 values in the comments):
find "$ION" -type f -printf '%s\n' | awk '{s+=$1} END {print s}'   # total bytes: 192461943 (archive: 193686231)
find "$ION" -type f | wc -l                                          # files: 4612
find "$ION" -type f -name '*.js' | wc -l                             # JS: 4014
find "$ION/assets/v1" -maxdepth 1 -type f -name '*.js' | wc -l       # assets/v1 JS: 4004
for e in css png svg gif woff2 ttf woff mp3 webm mov wasm; do      # 24 55 379 0 40 21 20 9 1 1 3
  echo "$e $(find "$ION" -type f -iname "*.$e" | wc -l)"; done
find "$ION/assets/v1" -type f -name '*.svg' | wc -l                  # assets/v1 SVG: 340
find "$ION/_frame-rt/_runtime" -type f 2>/dev/null | wc -l           # 0 (dir removed in v4.29.0; was 44)
comm -12 <(ls "$OLD_ION/assets/v1") <(ls "$ION/assets/v1") | wc -l   # surviving file names vs the previous audit

# 8. Config key catalog: SPA vs app.asar zod schema must agree; diff against the previous release
grep -ahoE 'flatKey:["`][A-Za-z0-9_]+["`]' "$ION/assets/v1/"*.js | sort -u | wc -l
grep -ahoE 'flatKey:["`][A-Za-z0-9_]+["`]' tmp/app.asar.contents/.vite/build/index*.js | sort -u | wc -l
```

If the mountPath pattern changed or new platform-gated paths appeared, update `fix_ion_dist_linux.nim` and this baseline.
