## Patterns to Monitor on Upstream Updates

When a new version drops, re-run these checks against the fresh `ion-dist/`:

Use GNU `grep -a` (or python), not `rg`: the minified chunks can contain NUL bytes and `rg` then silently returns nothing, even with `-a`. Character classes must be POSIX (`[A-Za-z0-9_$]`), `\w` inside brackets is not portable.

```bash
ION="$WORK_DIR/tree/resources/ion-dist"

# 1. Find the two patch targets by content (filenames AND chunk families change;
#    sub-patch A = the only mountPath:{ file, sub-patch B = the only ternary file)
grep -alE 'mountPath:\{mac:' "$ION/assets/v1/"*.js
grep -aoE '[A-Za-z0-9_$]+=== *[A-Za-z0-9_$]+\.Win32\?[A-Za-z0-9_$.]+\.win:[A-Za-z0-9_$.]+\.mac' "$ION/assets/v1/"*.js
grep -al 'org-plugins' "$ION/assets/v1/"*.js   # also hits the admin-plugins data-testid chunk (c90a58c4a-*) - not a target

# 2. Verify org-plugins still only has mac/win (or was updated upstream)
grep -aoE 'mountPath:\{.{0,200}\}' "$ION/assets/v1/"*.js

# 3. Check for new platform-gated code
grep -al 'darwin' "$ION/assets/v1/"*.js | wc -l

# 4. Check for new mac/win-only paths without linux
grep -aoE '/Library/Application Support.{0,60}' "$ION/assets/v1/"*.js
grep -aoE '%ProgramFiles%.{0,60}' "$ION/assets/v1/"*.js

# 5. Verify platform enum still exists (location-agnostic: the enum left index-*
#    at v1.28929.0 and hops shared-* chunk numbers between releases - grep the dir)
grep -aoE 'Darwin="darwin".{0,40}Linux="linux"' "$ION/assets/v1/"*.js

# 6. Check for new IPC bridges or native calls (since v1.32352.1 the bindings
#    live in shared-* chunks, no longer in index-*.js - grep the whole dir)
grep -ac 'claudeAppBindings' "$ION/assets/v1/"*.js | grep -v ':0$'

# 7. Bundle size sanity check (large changes = structural refactor)
du -sh "$ION"
```

## Config Key Schema

The 3P config supports these key categories (defined in the SPA's Zod schema; 143 unique `flatKey` entries at v1.46388.2). Field metadata attributes seen since v1.46388.2: `readers:["m365"]` marks keys read by the Microsoft 365 add-in (several are explicitly "not read by Claude Desktop"), `remotePolicy:{hotApplied:!0}` marks keys the running app applies without a relaunch, `betaFeatureKey` ties a key to a beta feature (`sshRemoteSessions`).

- **Connection:** `inferenceProvider`, `deploymentOrganizationUuid`, `disableDeploymentModeChooser`, `disableMultiAccount` (new in v1.46388.2; "Single account only", boolean default off, fail-closed on, 1p scope, gated `availableInVersion:"@next"`, `visibility:"public-undocumented"`), `dictationEnabled` (new in v1.46388.2; 3p scope, `availableInVersion:"1.44121.1"`, `public-undocumented`, hybrid scope `excluded` - "typically supplied by your bootstrap server when the gateway offers dictation"), `inferenceStreamIdleTimeoutSec` (new in v1.46388.2; extra seconds to wait on a streaming response that sends only keep-alive pings, gateway provider only, default 300, 3p scope, `availableInVersion:"1.44121.1"`)
